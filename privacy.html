Robot Jury Bot: Privacy Policy

Last updated: 3 October 2026

Robot Jury Bot is a private tool used only by the owner of the YouTube channel The Robot Jury to upload the channel's own videos, post comments on them and read the channel's own YouTube Analytics.

Data we access

With the channel owner's permission, the tool uses the YouTube Data API and YouTube Analytics API to upload videos, edit their metadata, post comments and read view statistics for the owner's channel only. It does not access any other user's account or data.

How data is used and stored

Statistics are saved as private reports for the channel owner. No data is sold, shared with third parties or used for advertising. OAuth tokens are stored only in the owner's private environment.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. The tool's use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.
